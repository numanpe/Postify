# Bundled fonts

Used by the poster render pipeline (`src/lib/poster/`) so it works
offline with no runtime font-fetching dependency, per CLAUDE.md's
free-first principle.

- **Lato** (Latin, Regular + Bold) — https://fonts.google.com/specimen/Lato
- **Tajawal** (Arabic, Regular + Bold) — https://fonts.google.com/specimen/Tajawal

Both are licensed under the SIL Open Font License 1.1 (`OFL.txt`),
which permits bundling and redistribution. Files fetched from the
[google/fonts](https://github.com/google/fonts) repository, which
serves the same static instances Google Fonts itself distributes.
